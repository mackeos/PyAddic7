# pyaddic7ed (compatibility alias)

This PyPI project is a compatibility alias. The project formerly known as
`pyaddic7ed` was renamed to **PyAddic7** and is published on PyPI as
**[`pyaddic7`](https://pypi.org/project/pyaddic7/)**.

Installing `pyaddic7ed` pulls in `pyaddic7`, which provides:

- the `pyaddic7` and `pyaddic7ed` import names,
- the `addic7ed` and `pyaddic7` CLI commands,
- everything documented at <https://github.com/Mackeos/PyAddic7>.

New code should use `pip install pyaddic7` and `import pyaddic7`.
